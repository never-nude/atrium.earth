# Figures, guardians, and stories — 50 additions

Part of the expansion to 1,000 public works. This batch adds 50 distinct works to production commit `0012f37151f1d35f7fa4141986157b6ad169141c`, increasing the public collection from 860 to 910. The catalog also retains eight previously hidden records.

## Selection and sources

Museum objects, public sculpture and other documented cultural objects are eligible for this expansion. Every work is assigned to an existing wing. Model identifiers, collection links, accession numbers and visual references were checked against the baseline to avoid adding another scan of the same object. Paired or assembled objects are counted once.

## Model preparation and review

Original files were matched to the published archive sizes and checksums. Direct archive links and the public Objaverse mirror supply identical files; actual retrieval URLs are recorded in the manifest. The 50 optimized previews total 59.10 MB and use immutable content-hashed URLs on Atrium’s model domain.

The model license applies to the downloaded archive version. This does not change rights in separate museum photographs or imply that every asset on a museum website shares the model’s license. Attribution identifies the source contributor and Atrium’s geometry and texture optimization. Unknown manufacture dates and materials remain blank; acquisition dates are not substituted for creation dates.

Each model was reviewed from six directions, with additional adjusted views when needed. Saved camera angles, object rotation and framing also generate its thumbnail. Original breaks, repairs, display supports, untextured surfaces and limits of surface-only scans remain part of the source representation. The orientation report records relevant limitations.

## Verification

Wing fixtures, asset completeness and production build passed. Release validation checks unique additions, unchanged baseline records and viewing settings, compiled orientations, model hashes, thumbnails and posters. Public remote models were downloaded and checked for matching bytes, content type and CORS. Browser review covers the new gallery and interactive object viewing. After deployment, all new live pages, thumbnail checksums, model sizes and starting transforms are checked again.

The cumulative local review page is `/preview/road-to-1000/`; production builds exclude this preview route.

## Metadata qualifications

The two Thai Sawankalok ceramic figures/vessels have conflicting chronological signals in their museum records, so their displayed dates remain unconfirmed. The bird-shaped mace head follows the detailed Yale object description and visual evidence; a generic source heading calls it a vessel fragment. He Xiangu is shown seated in the supplied model. The Qilin record mentions a wooden display base, while the model presents the ceramic figure.
