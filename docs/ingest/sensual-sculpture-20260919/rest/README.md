## Source and review notes

All models were inspected from front, side and rear; each ships with a real WebP thumbnail. Source geometry and texture processing are recorded in adjacent acquisition reports. Original files remain in the local research archive. No synthetic reconstruction or hole filling was used.

Inner Voice and Undine have only surrounding floor fragments removed; museum supports remain. Night retains gaps at the base edge, disclosed in its record. Psyche has softer surface detail and retains a thin mounting slab. Sluggard’s exact medium, accession and physical dimensions remain unresolved and are omitted. Odalisque is anonymous, inspired by Pradier; the Christie’s inscription does not establish a Pajou attribution.

CC0/CC BY/CC BY-SA license links and source credits are public. Mia previews and rendered thumbnails remain CC BY-SA 4.0. All size reviews explicitly distinguish documented measurements from geometry calibration. No strict physical calibration is claimed for this batch.

## Validation

Wing assignment, newest-additions grouping, catalog asset verification and production build passed. The 11 earlier source models and derivatives were inspected at three angles. All 1,205 pre-batch catalog records and all existing runtime metadata are unchanged. Whole-catalog physical-dimension and spatial-eligibility checks have pre-existing missing-review failures outside this batch; those unrelated records were not changed. Each new work has an explicit dimension-review status and spatial-eligibility entry.
