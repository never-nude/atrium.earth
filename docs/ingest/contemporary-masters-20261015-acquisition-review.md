## Source preservation

The 24 actual authenticated provider GLBs total 315,237,320 bytes. Their incoming bytes and SHA-256 values are recorded separately from discovery API archive-size estimates. No fetched source was decoded. Sources were copied without modification; integrity welding/degenerate-face removal occurred only on analysis copies. Public derivatives retain available authored textures/PBR maps and vertex colors, with geometry and texture optimization recorded in the JSON report.

All 24 unmodified provider files have additionally been copied to a permanent private cloud archive with their source/license/hash manifest and README. Root verified all cloud filenames, byte sizes and non-shared states; cloud content hashes were not read back. Private links and identifiers are excluded from this repository.

The sources-only GitHub backup is temporary: artifact 11996462388, 630,486,634 bytes, expires 13 January 2027. It contains originals and unchanged source-name copies; its 90-day retention is not the permanent archive. No raw source archive was downloaded for this visual review.

## Representation and size

Tir is an explicit frontal assemblage-surface capture. IBM mural, Barcelona Airport wall and Fundació tapestry are explicit frontal 3D surface captures; apparent reverse textures do not document physical reverse surfaces. The tapestry preserves broad relief and fibrous perimeter, with finer yarn detail mostly in texture. Airport canopy/building context and Stella wall/floor residue are retained and distinguished from the artwork. The Miró monolith has two genuinely distinct decorated faces.

Twenty provisional public works have explicit physical-dimension review records and disabled verified-size decisions. Published sculpture dimensions are not silently applied to room, support or façade bounds. Catalogue-derived starting sizes remain labelled approximate; no new exact-size calibration is asserted.

The narrow viewer/thumbnail fix protects authored COLOR_0 and source material multipliers/PBR values, preserves vertexColors when converting nonstandard materials and retains treatment of uncolored legacy meshes. Regression tests execute the actual functions from both rendering paths. Humming and the existing Arman Accord Final require final corrected thumbnails/posters.
