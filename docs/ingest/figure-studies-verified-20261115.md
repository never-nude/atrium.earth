This import adds 30 documented physical works. The latest import is a single batch, `figure-studies-verified-20261115`. The new works stay outside homepage and featured selection. Captures of casts and replicas are identified as such in each record.

Kaitlyn Andrus and Enrique Grim were excluded at the owner's direction. Sara Leone's digital anatomy study is excluded under the physical-work requirement. The British Museum's *Ain Sakhri Lovers* is included for noncommercial display in this batch. The model retains CC BY-NC-SA 4.0, the original texture, a link to the institution's model package, and credit to Daniel Pett and the British Museum. The OBJ package was converted to GLB for display. The ordinary automated import still excludes noncommercial assets.

The reviewed GLBs are served from immutable model URLs. Both transfers passed complete public hash readback. A separate readback checked MIME, byte length, SHA-256 and cross-origin access from Atrium for every selected model. The display model of *Eve of Autun* was compressed with Draco, with the source JPEG and index count retained. Cleveland's torso uses a compatibility conversion of the original material format. Untextured source geometry uses neutral display material. The new thumbnails were rendered from the serving models.

All 40 provider source packages, including the review holds, are covered by the verified private archive and portable recovery map. The public catalogue contains only the selected works.
